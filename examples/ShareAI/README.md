# ShareAI
Sharing the web content to this ShareAI app and get quick summary of the web page.

This example combines the local LLM ability of [llama.cpp](https://github.com/ggml-org/llama.cpp) with web scraping to build a summarizer.

Clone the cookbook with `git clone --recurse-submodules` to get the pinned llama.cpp source.
